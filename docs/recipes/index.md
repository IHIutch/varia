# Recipes

Copy a definition into your project, change its import to `variacss`, and register it in your plugin's `components` array.

Recipes provide styles and example markup. Your application handles interactions and accessibility. For example, it must manage dialog focus and menu keyboard navigation.

| Pattern | Recipes |
| --- | --- |
| Variants and compounds | [Button](/recipes/button), [icon button](/recipes/icon-button) |
| Base and state styles | [Card](/recipes/card), [form input](/recipes/form-input), [spinner](/recipes/spinner) |
| CSS variable overrides | [Avatar](/recipes/avatar) |
| Slots | [Dropdown](/recipes/dropdown), [modal](/recipes/modal) |
| Responsive layout | [Grid](/recipes/grid) |
