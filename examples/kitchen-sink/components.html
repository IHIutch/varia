What is varia? ▾
A build-time variant system on top of Tailwind. Trades raw utility classes for compressed component classes via shortcuts.
How does it differ from CVA? ▾
CVA is framework-side and generates class names at runtime. varia compiles recipes into Tailwind component classes at build time — emits real CSS, no runtime function calls.
Does it work with React? ▾
Yes — varia outputs CSS, so any framework that renders class strings is fine. The class compression is most valuable in framework-agnostic templates (raw HTML, Vue/Svelte templates).
