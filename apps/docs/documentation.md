# Documentation

Varia lets you author component styles with Tailwind utilities and use them through ordinary CSS classes. Your application supplies markup, interaction behavior, and accessibility.

## Get started

Follow [Quickstart](/quickstart) to build a styled button in a standalone Vite project. The tutorial chooses one setup and shows the expected result at each step.

Already building Tailwind CSS? Follow [Tailwind CSS](/tailwind).
